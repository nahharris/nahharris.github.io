Here begins my journey contributing to Patch Hub.

## Patch Hub

Patch Hub is a project that is part of [`kworkflow`](https://github.com/kworkflow) whose objective is to create a command line interface to view patches submitted to the Linux kernel through the [lore](https://lore.kernel.org/) API.

The project was started by [David de Barros Tadokoro](https://github.com/davidbtadokoro), an active contributor to the kw project, and is made in Rust (a language that I really like).

## What has been done so far

Patch Hub is already in the _alpha_ stage where the main functionality is already implemented: viewing patches. However, the project still needs polishing in terms of usability, documentation and code.

In my first few weeks contributing to the project, I tried to help with project _design_ decisions and fixing some issues I found.

But my main focus was on understanding the project architecture and the libraries being used.
