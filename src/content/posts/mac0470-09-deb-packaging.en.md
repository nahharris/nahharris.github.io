We had a packaging workshop for Debian with [Joenio Marques da Costa](https://joenio.me/) in one of the classes, where he led us to make an example package with Perl's _Hello World_ library.

## Part 1 - Virtual Machine

The first part of the tutorial was to create a virtual machine with Debian Testing (to have more up-to-date versions of the packages) and a standardized environment to carry out packaging. To do this, I used the Virt Manager that we had already used at the beginning of the course and followed the Debian tutorial on [Debian Testing](https://wiki.debian.org/DebianTesting). Then I installed the dependencies he indicated in the tutorial and that was it.

## Part 2 - Creating package for Acme::Helloworld

We used `dh-make-perl` to download the library source code and create the file templates needed to create the package. The main files created are inside the `debian/` folder and here we will only modify `copyright`, `control` and `changelog`.

### Copyright

In this file we list the licenses used in the project. The file generated by `dh-make-perl` is incomplete, so we need to find the license and copyright year to correct the file.

### Control

Here we list the project dependencies. In the template produced, the correct dependencies are already listed, we just updated (following a suggestion from Joênio) the line `Standards-Version` to:

```yaml
Standards-Version: 4.7.0
```

And finally we check if everything is correct with the file with the `cme` tool

### Changelog

As the name suggests, this file lists the changes that have been made since the last version of the project.

## Part 3 - Building the Package

To build the package, simply

```bash
sudo pbuilder create
BUILDER=pbuilder git-pbuilder
```

I didn't have any problems while creating the package other than the warnings mentioned on Joênio's blog

Finally, I tested the package installation with

```bash
sudo dpkg -i ../libacme-helloworld-perl_0.01-1_all.deb
```

The package is created in the parent directory of the current directory
