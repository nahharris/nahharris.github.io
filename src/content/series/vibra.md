Vibra is my exploration of what a programming language can be when coding agents are central to how software is written and maintained.

It brings together explicit language design, static types and effects, and structured tools to help agents make changes that people can understand and trust. The project is currently in pre-alpha: there is already a language implementation to explore, and plenty left to build before the first alpha, v0.1.

In this series, I'll share the ideas behind Vibra, how the language is taking shape, and what I learn along the way.
